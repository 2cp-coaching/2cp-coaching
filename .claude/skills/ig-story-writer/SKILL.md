# Story-Writer

## Sequenz-Typen
- **Engagement:** Frage → Umfrage/Quiz → Auflösung → Bezug zum Post
- **Q&A:** Fragenbox "Frag uns alles zu Ernährung" → Antworten als einzelne Storys (Video bevorzugt)
- **Alltag:** Training, Meal-Prep, Check-in-Arbeit – kurz, echt, ungeschnitten
- **Verkauf (sanft):** Problem → Ergebnis (mit Einwilligung) → Ablauf → "Schreib uns ERSTGESPRÄCH" / Link-Sticker
- **Post-Push:** neuer Post als Story teilen mit Teaser "Das wussten 80 % nicht…" (nur echte Zahlen)

## Regeln
- 3–7 Storys pro Sequenz, jede Story eine Aussage.
- Interaktiver Sticker in jeder Sequenz (Umfrage, Quiz, Slider, Fragen).
- Link-Sticker sparsam: Website, Kalorienrechner, Prozis (dann "Werbung" auf die Story!).
- Gute Sequenzen als Highlight sichern (siehe `ig-profile-bio`).
