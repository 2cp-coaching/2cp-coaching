# Caption-Writer

## Aufbau
1. **Hook** (erste ~125 Zeichen, vor "mehr") – aus `ig-hook-writer`.
2. **Mehrwert** – 3–6 kurze Absätze oder eine Liste mit ✅. Ein Gedanke pro Absatz.
3. **Persönlicher Satz** – Erfahrung von Christian oder Corinna, wenn passend.
4. **Ein CTA** – passend zum Ziel:
   - Speichern: "Speicher Dir das für Dein nächstes Training."
   - Kommentar: "Schreib uns 'PLAN', wenn Du …"
   - DM: "Schreib uns eine Nachricht mit 'ERSTGESPRÄCH'."
   - Link: "Kalorienrechner findest Du über den Link in unserer Bio."
5. **Hashtags/Keywords** – aus `ig-hashtags-seo`.

## Längen
- Reel: 50–150 Wörter. Karussell/Wissen: 120–250 Wörter. Ergebnis-Post: Geschichte mit Kontext, gern länger.

## Regeln
- Ton laut `ig-brand-voice`. Du/Dein groß. Max. 2–3 Emojis.
- Keine erfundenen Zahlen. Gesundheitliche Themen mit Hinweis "ersetzt keine ärztliche Beratung", wo sinnvoll.
- Prozis: erste Zeile "Werbung" / "Anzeige", Code 2CPCOACHING, Paid-Partnership-Label setzen.

## Ausgabe
2 Varianten (kurz/lang), fertig zum Kopieren, Hashtags getrennt darunter.
